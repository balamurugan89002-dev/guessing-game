🎯 Number Guessing Game

A simple number guessing game built to practice programming and web development.

🛠️ Technologies

- HTML
- CSS
- JavaScript / TypeScript
- Vite

🎮 How to Play

1. Enter a number.
2. Submit your guess.
3. Follow the feedback.
4. Keep guessing until you find the correct number.

🚀 Run Locally

git clone https://github.com/balamurugan89002-dev/guessing-game.git
cd guessing-game
npm install
npm run dev

Project documentation is available in the "docs" folder.
